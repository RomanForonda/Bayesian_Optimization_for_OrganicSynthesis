# Bayesian Optimization Learning

Learning Bayesian Optimization with BayBE through a simulated chemical reaction optimization problem.

## Objective

Optimize reaction yield as a function of:

- Temperature
- Reaction time

## Tools

- Python
- BayBE
- BoTorch
- Gaussian Processes
- NumPy
- Matplotlib

## Current workflow

The project currently implements:

1. Definition of a continuous search space.
2. Definition of a maximization objective.
3. Bayesian optimization using BayBE.
4. Simulated reaction experiments.
5. Visualization of the optimization landscape.
6. Visualization of optimization convergence.
